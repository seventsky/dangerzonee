    pra analisar uma aplicação web eu preciso entender como ela funciona quando tá tudo certo. requisição, resposta, rota, autenticação, sessão, cookie, validação, entrada do usuário, o que roda no frontend, o que roda no backend e o que o servidor faz com tudo isso.

    não dá pra entender uma vulnerabilidade sem entender o funcionamento normal. por isso o desenvolvimento web deixou de ser uma coisa separada dos meus estudos de segurança. uma coisa depende da outra.
