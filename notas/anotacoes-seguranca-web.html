Anotações de segurança web

Pra analisar uma aplicação web, preciso entender requisições, respostas, rotas, autenticação, sessões, cookies, validação, frontend, backend e servidor.

Também estudei a relação entre frontend, backend, servidor, requisições, respostas, autenticação, sessões, cookies e entrada de usuário. Pra entender uma vulnerabilidade, preciso entender o funcionamento normal da aplicação. Por isso o desenvolvimento web deixou de ser uma área separada dos meus estudos de segurança.
