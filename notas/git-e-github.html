    Git e GitHub

    Repositórios, README e GitHub Pages.

    Git e GitHub chegaram junto com os primeiros projetos. Repositório, README, organização de pasta, GitHub Pages. Hoje o GitHub não é só onde eu guardo código: é onde eu organizo o que tô fazendo, e é onde mora este portfólio.

    Também aprendi a importância de estruturar e documentar direito, principalmente quando eu quero que outra pessoa abra o repositório e entenda o que foi feito.

    Quebrar a cabeça, procurar mil e uma soluções pra uma página quebrada, um repositório errado. É isso que a gente faz quando não tem uma grade de faculdade. Tudo que você resolve vira aprendizado, e resolver problema comum também é estudar.
