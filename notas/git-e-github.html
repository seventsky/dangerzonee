    Git e GitHub

    Repositórios, README e GitHub Pages.

    Quando comecei a criar projetos, Git e GitHub entraram nos estudos junto. Passei a mexer com repositórios, arquivos, README, organização de projeto e publicação no GitHub Pages. O GitHub deixou de ser só um lugar pra guardar código: uso ele pra organizar o que estou desenvolvendo e pra montar meu portfólio.

    Também aprendi a importância de estruturar bem um projeto e de documentar, principalmente quando quero que outra pessoa abra o repositório e entenda o que foi feito.

    Quebrar a cabeça com algo, procurar mil e uma soluções pra um problema, uma página quebrada, um repositório errado. É isso que a gente faz quando não tem uma grade de estudos estruturada numa faculdade. Tudo que você resolve vira aprendizado, e resolver problema comum também é estudar.
