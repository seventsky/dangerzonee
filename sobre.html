    Sobre mim

    Eu sou só uma escritora. E se código também pudesse virar poesia?

    Vim de uma família pobre, de uma comunidade no Rio de Janeiro. Conheci a internet ainda nova, numa lan house em cima de uma loja de material de construção. Lá eu "hackeava" jogo e rede social pros meus parentes, sem fazer ideia do que aquilo significava.

    Antes do código veio a arte. Sempre gostei de poesia, de construir coisas com palavras, com desenho, com formas que mostravam como eu via o mundo. Não deu certo.

    Caí no subemprego porque era o que tinha. Tentar uma segunda faculdade era luxo: eu não tinha tempo pra isso. "Ser rico é ter tempo, e tempo é dinheiro, e é por dinheiro que a gente se mata."

    Quando a vida melhorou, voltei a estudar, agora pensando no que dava pra fazer com o que eu gostava. Comecei por HTML, CSS e JavaScript, ainda sem saber direito a diferença entre estrutura, estilo e lógica. Depois vieram Python e um pouco de Java.

    Fazer site não bastava. Eu queria saber o que acontecia por trás: como um servidor responde, como os arquivos se conversam, o que acontece quando alguma coisa quebra. Foi aí que a segurança da informação entrou de vez. Linux, redes, segurança web, CTF, red team, monitoramento. Eu sempre gostei de investigar, e isso juntava tudo que eu passei a vida tentando entender.

    As três linguagens da web só fizeram sentido de verdade quando eu comecei meus próprios projetos e precisei que elas funcionassem juntas. O HTML é a estrutura, o CSS é a cara, o JavaScript é o comportamento.

    Aprendendo no erro

    Ler, ver tutorial e copiar é uma coisa. Fazer o próprio projeto é outra, porque é aí que os problemas aparecem. Um arquivo que existe e a aplicação não acha. Um botão que aparece na tela e não funciona porque o JS não carregou. Um CSS que não pega porque o caminho tá errado. Servidor local, localhost, porta. Foi assim que eu aprendi a investigar a estrutura do projeto em vez de ficar encarando o código da tela.

    Quase tudo eu aprendi no meu próprio computador. Ele deixou de ser só a máquina onde eu estudo e virou laboratório: é onde eu programo, uso Linux, rodo servidor, mexo com Git e Wine, configuro serviço, leio log e testo aplicação. Quando a parte gráfica dele quebrou, eu fui obrigada a entender pedaços do sistema que provavelmente só ia estudar muito depois. Contei essa história aqui.

    O caminho ficou bem maior do que eu imaginava quando comecei.
